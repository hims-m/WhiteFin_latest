    How it works

    Nine agents cooperate through a LangGraph state machine. They don't just run in a line: the profiling agent can stop and ask you questions, two pairs of agents run in parallel, and a validator agent can reject the portfolio and send it back for revision with specific fixes.

    All numbers come from deterministic finance code. An optional LLM only rewrites the wording, and its text is rejected if it changes any figure.
